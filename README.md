# 🐍 المتصفح النصي - Mini Browser

هذا برنامج متصفح ويب يعمل عبر سطر الأوامر (Terminal)، مكتوب بلغة بايثون باستخدام مكتبات `urllib` و `html.parser` الأساسية (بدون تحميل أي مكتبات خارجية).

## ✨ المميزات
- فتح أي موقع (HTTP / HTTPS) وعرض عنوان الصفحة.
- عرض جميع الروابط والصور الموجودة في الصفحة.
- حفظ سجل التصفح (History) وعرض الكوكيز (Cookies).
- تحميل جميع الصور من الصفحة المفتوحة وحفظها في مجلد `downloads`.

## 🚀 طريقة التشغيل
1. تأكد من تثبيت بايثون 3 على جهازك.
2. افتح التيرمينال في مجلد الملف.
3. اكتب الأمر التالي:
   ```bash
   python main.py
